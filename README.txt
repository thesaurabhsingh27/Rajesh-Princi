RAJESH & PRINCI — WEDDING INVITATION

PUBLISHING UPDATE
1. Upload index.html, style.css, and script.js to the root of your GitHub repository.
2. Commit the changes. GitHub Pages will redeploy automatically.
3. Open https://thesaurabhsingh27.github.io/Rajesh-Princi/ and test on mobile.

FEATURES
- Animated double-door wedding entrance. Guests tap Open the Invitation.
- Original gentle instrumental-style melody generated in the browser using Web Audio. No copyrighted recording or external audio file is used.
- Music toggle, floating floral particles, scroll reveal, progress bar and wedding countdown.
- Responsive editorial wedding design in wine, antique gold and ivory.

MUSIC NOTE
Browsers block autoplay. The melody begins only after the visitor taps Open the Invitation. The music button can turn it off or on later.

PRIVACY
The repository is public. The Barat departure residential address has deliberately been omitted from this public version. Anyone with the link can open and forward the invitation. The noindex setting is advisory, not password protection.
