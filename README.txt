RAJESH & PRINCI — WEDDING INVITATION WEBSITE
==============================================

This is a free, one-page scrolling wedding invitation website based on the invitation image you provided.
It is designed to feel editorial, minimal and premium rather than like a generic template.

HOW TO PREVIEW
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Double-click index.html (or right-click > Open with > Chrome).
4. Scroll down the page to see the full invitation and reveal animations.

WHAT IS INCLUDED
- Long-form invitation with natural scrolling
- Scroll-reveal animations and reading progress bar
- Mobile-friendly layout
- All names, dates, ceremonies, timings, family details and addresses transcribed from your card
- Google Maps directions link
- Optional sound button (add your own licensed assets/ambience.mp3)

BEFORE PUBLISHING — PLEASE VERIFY
The following spellings are transcribed from the supplied card and may need correction:
- "Nevuter" (11 Dec event)
- "Gurchari" (12 Dec event)
- "Swari Devi" (grandmother's name)
- "Khatia Baba Marg" (residence address)
Please check these against the original printed card.

The venue and residence addresses are included as printed. Verify map pin and spelling before sharing publicly.

FREE PUBLISHING WITH GITHUB PAGES
1. Sign in or create a free account at https://github.com/
2. Create a PUBLIC repository named rajesh-princi-wedding.
3. Upload index.html, style.css, script.js and the assets folder.
4. Open repository Settings > Pages.
5. Under "Build and deployment", choose "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then Save.
7. Wait for GitHub Pages to publish. The site URL will appear on the Pages settings screen.

IMPORTANT
- GitHub Pages hosting for a public repository is free. You do not need to buy a domain.
- The site does not collect or store RSVP submissions.
- The sound button is optional and will only work if you add your own licensed MP3 named ambience.mp3 inside assets.
- Google Fonts need an internet connection. The website still works with fallback fonts if unavailable.
- Since this website is public, consider whether you want to publish the family residence address and RSVP names.
